**1. Create `src/features/wallet/components/ErrorState.tsx`:**

A small presentational component used by both balance and transaction error states. It renders an error message line and a blue "Retry" text button.

```typescript
import { Text, TouchableOpacity, View } from 'react-native';

type ErrorStateProps = {
  message: string;
  onRetry: () => void;
};

export function ErrorState({ message, onRetry }: ErrorStateProps) {
  return (
    <View className="items-center gap-2 py-4">
      <Text className="text-sm text-gray-500 text-center">{message}</Text>
      <TouchableOpacity onPress={onRetry}>
        <Text className="text-sm text-blue-600">Retry</Text>
      </TouchableOpacity>
    </View>
  );
}
```

Key details:

- `message` prop is a string (not nullable) — callers only render ErrorState when error exists
- `onRetry` is required — every error state has a retry affordance
- Retry button uses `text-sm text-blue-600` matching existing "Copy" and "Disconnect" text button patterns
- No icon — consistent with existing ConnectionError which uses text only
- `py-4` vertical padding keeps similar visual weight to the content it replaces

**2. Update `src/features/wallet/components/ConnectionError.tsx`:**

Replace the `message: string | null` prop interface with `hasError: boolean`. Hard-code the friendly error copy "Couldn't connect wallet" instead of rendering the raw JS error string.

The updated component:

```typescript
import { Text, View } from 'react-native';

type ConnectionErrorProps = {
  hasError: boolean;
};

export function ConnectionError({ hasError }: ConnectionErrorProps) {
  if (!hasError) return null;

  return (
    <View className="mt-2">
      <Text className="text-red-600 text-sm text-center">
        Couldn't connect wallet
      </Text>
      <Text className="text-gray-500 text-sm text-center mt-1">
        Tap Connect Wallet to try again.
      </Text>
    </View>
  );
}
```

Changes from current:

- Prop renamed from `message: string | null` to `hasError: boolean`
- Guard changed from `if (!message)` to `if (!hasError)`
- `{message}` replaced with fixed string `Couldn't connect wallet`
- No retry button added — the existing Connect Wallet button IS the retry (per user decision)
- Hint text "Tap Connect Wallet to try again." preserved unchanged
