# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (shadcn not applicable — Expo/React Native stack) |
| Preset | not applicable |
| Component library | none (NativeWind v4 utility classes only) |
| Icon library | none (no icons in this phase) |
| Font | System default (no custom font in this phase) |

**Note (source: CONTEXT.md):** Phase 1 produces no user-facing features. The only UI surface is a temporary smoke test screen on the index route displaying AppKit initialization status and masked environment variable values. This screen is replaced in Phase 2.

**Note (source: codebase scan):** `tailwind.config.js` uses `nativewind/preset` with no custom token extensions. No components exist yet in `src/components/`. The project uses NativeWind v4 `className` props with Tailwind classes — inline `style` objects are forbidden per `CLAUDE.md`.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (`p-1`) | Icon gaps, inline padding |
| sm | 8px (`p-2`) | Compact element spacing, label-to-value gaps |
| md | 16px (`p-4`) | Default element spacing, card padding |
| lg | 24px (`p-6`) | Section padding, row separation |
| xl | 32px (`p-8`) | Layout gaps, screen-level horizontal padding |
| 2xl | 48px (`p-12`) | Major section breaks |
| 3xl | 64px (`p-16`) | Page-level spacing |

Exceptions:
- Touch targets: minimum 44px height for any interactive element (React Native accessibility guideline). Use `min-h-[44px]` on any tappable row.

## Typography

NativeWind maps Tailwind font-size tokens to React Native `fontSize`. No custom font is introduced in this phase — system font is used throughout.

| Role | Size | NativeWind Class | Weight | RN Weight | Line Height |
|------|------|-----------------|--------|-----------|-------------|
| Body | 14px | `text-sm` | Regular | 400 | 1.5 (`leading-snug`) |
| Label | 12px | `text-xs` | Regular | 400 | 1.5 (`leading-snug`) |
| Heading | 20px | `text-xl` | Semibold | 600 | 1.2 (`leading-tight`) |
| Status | 16px | `text-base` | Semibold | 600 | 1.4 (`leading-normal`) |

Rules:
- Exactly 4 sizes declared above. No other sizes are permitted in this phase.
- Exactly 2 weights: 400 (`font-normal`) and 600 (`font-semibold`).
- Body line height 1.5, heading line height 1.2 — use NativeWind `leading-*` classes.

## Color

No custom color tokens are added in this phase. NativeWind's default Tailwind palette is used directly via class names.

| Role | Value | NativeWind Class | Usage |
|------|-------|-----------------|-------|
| Dominant (60%) | white (`#FFFFFF`) | `bg-white` / `bg-gray-50` | Screen background, surface fill |
| Secondary (30%) | gray-100 (`#F3F4F6`) | `bg-gray-100` | Status rows, env var value containers |
| Accent (10%) | green-600 (`#16A34A`) for success / red-600 (`#DC2626`) for failure | `text-green-600` / `text-red-600` | AppKit init status indicator text only |
| Destructive | not applicable | — | No destructive actions in this phase |

Accent reserved for:
- AppKit initialization status text ("OK" → green-600, "Error" → red-600)
- Nothing else. All other text uses gray-900 or gray-500.

Text colors:
- Primary text: gray-900 (`text-gray-900`)
- Secondary/label text: gray-500 (`text-gray-500`)
- Masked key values: gray-400 (`text-gray-400`) with monospace style via `font-mono`

## Copywriting Contract

Phase 1 has no user CTAs, no empty states from user data, and no destructive actions. The only copy is diagnostic output on the smoke test screen.

| Element | Copy |
|---------|------|
| Screen title | "Smoke Test" |
| AppKit section heading | "AppKit" |
| AppKit status — success | "OK" |
| AppKit status — error | "Error: {message}" |
| Env vars section heading | "Environment Variables" |
| Reown Project ID label | "EXPO_PUBLIC_REOWN_PROJECT_ID" |
| Etherscan API key label | "EXPO_PUBLIC_ETHERSCAN_API_KEY" |
| RPC URL label | "EXPO_PUBLIC_RPC_URL" |
| Masked key placeholder | "••••••{last4}" (last 4 chars visible, preceding chars masked) |
| RPC URL display | Show full URL — not a secret (Infura project IDs are in the URL but not security-sensitive for a read-only app) |
| Missing env var value | "NOT SET" (red-600) |
| Primary CTA | None — this is a diagnostic screen only. No CTA exists. |
| Empty state heading | Not applicable (no data-driven lists in this phase) |
| Empty state body | Not applicable |
| Error state | AppKit error: "AppKit failed to initialize. Check Metro logs for details." |
| Destructive confirmation | None — no destructive actions in this phase |

## Component Inventory

The smoke test screen (`src/app/index.tsx`) uses only React Native primitives styled with NativeWind. No shared components are introduced or registered to `src/components/ui/` in this phase.

| Component | Source | Notes |
|-----------|--------|-------|
| `View` | react-native | Screen container, section containers, row containers |
| `Text` | react-native | All text — headings, labels, values, status |
| `ScrollView` | react-native | Wraps the screen in case content overflows |

No `TouchableOpacity`, `Pressable`, or `Button` elements — this screen is read-only output only.

---

## Interaction Contract

Phase 1 has no interactive elements on the smoke test screen. The screen is static diagnostic output only.

| Interaction | Behavior |
|-------------|----------|
| Screen render | Synchronous. AppKit init status is read from a module-level boolean set during AppKit singleton initialization. No async loading state on this screen. |
| Tap | No tap targets on this screen. |
| Back navigation | Standard Expo Router stack back — no custom behavior. |

## Layout

The smoke test screen layout:

```
SafeAreaView (flex: 1, bg-white)
  ScrollView (flex: 1, px-8 py-6)
    Text "Smoke Test"          ← Heading, text-xl font-semibold, mb-6
    — Section: AppKit —
    Text "AppKit"              ← Label, text-xs text-gray-500, mb-2, uppercase
    View (bg-gray-100, p-4, rounded-lg, mb-6)
      Row: Text "Status" + Text "OK" | "Error: {msg}"
    — Section: Environment Variables —
    Text "Environment Variables" ← Label, text-xs text-gray-500, mb-2, uppercase
    View (bg-gray-100, p-4, rounded-lg)
      Row: label + masked value  ← Repeat for each of 3 env vars, separated by border-b border-gray-200
```

Row layout within sections: `flex-row justify-between items-center py-2`
