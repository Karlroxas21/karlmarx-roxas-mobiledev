Create `src/features/wallet/hooks/use-balance.ts` with two exports: the `useBalance` hook and a pure `formatBalance` function.

**`formatBalance(wei: bigint): string`** — Pure function, exported for testability:
1. Convert wei to ETH string: `ethers.formatEther(wei)` returns a decimal string
2. Parse to float: `parseFloat(ethResult)`
3. Check threshold: if `eth > 0 && eth < 0.0001`, return `'< 0.0001'`
4. Otherwise return `eth.toFixed(4)` (always 4 decimal places, no thousand separators)

Expected outputs (verified in research):
- `formatBalance(0n)` returns `'0.0000'`
- `formatBalance(1n)` returns `'< 0.0001'`
- `formatBalance(100000000000000n)` returns `'0.0001'`
- `formatBalance(1230000000000000000n)` returns `'1.2300'`
- `formatBalance(1234567800000000000n)` returns `'1.2346'`
- `formatBalance(1234567000000000000000n)` returns `'1234.5670'`

**`useBalance()` hook** — Returns `{ balance: string | null; isLoading: boolean; error: string | null }`:
1. Read `address` from `useWalletStore((s) => s.address)` — do NOT use useWalletConnection (that hook adds connect/disconnect logic not needed here)
2. `useState<BalanceState>` with initial `{ balance: null, isLoading: true, error: null }`
3. `useEffect` depending on `[address]`:
   - If `!address`, return early (no fetch)
   - Set `let cancelled = false` before async work
   - Reset state to `{ balance: null, isLoading: true, error: null }` at start
   - Create provider: `new ethers.JsonRpcProvider(ENV.INFURA_RPC_URL, undefined, { staticNetwork: true })` — staticNetwork avoids extra eth_chainId RPC call; do NOT use `StaticJsonRpcProvider` (removed in ethers v6)
   - Call `const raw = await provider.getBalance(address)` — returns native `bigint`
   - On success (if not cancelled): set `{ balance: formatBalance(raw), isLoading: false, error: null }`
   - On catch (if not cancelled): set `{ balance: null, isLoading: false, error: e instanceof Error ? e.message : 'Balance fetch failed' }`
   - Cleanup function: `return () => { cancelled = true; }`
4. Return state object

**Type definition** — Define locally in the hook file (no need to extend wallet types):
```typescript
type BalanceState = {
  balance: string | null;
  isLoading: boolean;
  error: string | null;
};
```

**Create `src/features/wallet/components/BalanceDisplay.tsx`:**

Props: `{ balance: string | null; error: string | null }`

Three states:
1. If `error` is truthy: render `<Text className="text-sm text-gray-500 text-center">Balance unavailable</Text>`
2. If `balance` is truthy: render `<Text className="text-3xl font-semibold text-gray-900 text-center">{balance} ETH</Text>`
3. If neither (should not happen when used correctly): render `null`

```typescript
import { Text } from 'react-native';

type BalanceDisplayProps = {
  balance: string | null;
  error: string | null;
};

export function BalanceDisplay({ balance, error }: BalanceDisplayProps) {
  if (error) {
    return (
      <Text className="text-sm text-gray-500 text-center">
        Balance unavailable
      </Text>
    );
  }

  if (balance) {
    return (
      <Text className="text-3xl font-semibold text-gray-900 text-center">
        {balance} ETH
      </Text>
    );
  }

  return null;
}
```

Typography from UI-SPEC: Display role = `text-3xl font-semibold`. Color: `text-gray-900` for balance, `text-gray-500` for error. Both centered.
